## Notes
- **Arrow close behaviour (verified).** `arrow::read_parquet()` (arrow 25.0.1) wraps an R connection via `make_readable_file()`. I ran a read-only check: after a successful `read_parquet(rawConnection(...))` on the committed `small.parquet` fixture (5 rows), `isOpen(con)` errors with "invalid connection". So arrow does close the connection, and the comment at `R/arrow.R:75-90` is accurate. The test must therefore treat the "invalid connection" error as closed. A plain `expect_false(isOpen(captured))` would error and fail.
- **testthat.** Version 3.3.2 is installed and `local_mocked_bindings` exists in its namespace.
- **Mocking.** `xet_open_connection` is internal to rxet and is called from `read_xet_parquet` in the same namespace, so `local_mocked_bindings(..., .package = "rxet")` intercepts the call under `devtools::test()`.
- **Fixture.** `helper-fixtures.R` provides `start_fixture_client()` (starts a local CAS server per test, with cleanup), `serve_fixture(client, "small.parquet")` (uploads the committed fixture and returns `hash`, `file_size`) and `fixture_path()`. `helper-local-cas.R` provides `skip_without_local_cas()`, which skips when the Rust extension, processx, or `local_cas_server` is missing.
- **Offline.** The test needs no `HF_TOKEN` and no network. It is gated only on the local server, as the spec requires.
- **Risk.** If a future arrow version starts leaving the connection open, the test fails as intended. The current arrow version closes it, so the test should pass today.
- **Constraints honored.** Only `tests/testthat/test-arrow-spatial.R` will be edited. The `R/` code is unchanged. No `.env` read, no token logged, no commit.
