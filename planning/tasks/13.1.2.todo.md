## Notes
- 13.1.1 present: `file_size`, `xet_reader_is_open`, reader-id `xet_stream_connection` in lib.rs.
- Registry<T> is Mutex<HashMap<String, Arc<T>>>; a `static` via lazy_static needs T: Send + Sync, so the trait object needs `+ Send + Sync` (WindowedReader's cache is a Mutex; source must be Sync too). Compiler will confirm.
- `reader.source()` returns `&Box<dyn ..>`; `.finish()` works via the blanket Box impl.
- document() may also touch man/ or NAMESPACE; those are outside scope, would revert.
- Risk: `rextendr::document()` compiles the crate (slow first time).
