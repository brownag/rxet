## Rust minimum (e)

**Enforced minimum: 1.85.0.** `tools/msrv.R` does not hard-code a version. It:
1. Reads `SystemRequirements` from `DESCRIPTION` (`tools/msrv.R:4–13`).
2. Requires the strings `cargo` and `rustc` to be present (`tools/msrv.R:16–22`).
3. Extracts the semver from the `rustc` part (`tools/msrv.R:28`, `:92`, which yields `1.85.0`).
4. Runs `rustc --version` and compares (`tools/msrv.R:102`, `compareVersion(msrv, current)`).
5. Stops when the installed rustc is older (`tools/msrv.R:110`).

So the value that is actually enforced comes from `DESCRIPTION`, which says 1.85.0.
