## Notes
- `tools/config.R` reads template `mv_fp` (line 77–81) then `readLines(mv_fp)` (line 97); a missing `src/Makevars.win.in` currently yields opaque `cannot open the connection`. Guard goes after the `mv_ofp` removal block (lines 90–94) and before line 97.
- `source("tools/config.R")` rewrites the tracked `src/Makevars`. On this repo/env: `DEBUG` unset, `NOT_CRAN` unset, `src/rust/vendor.tar.xz` absent ⇒ `.cran_flags=""`, `.profile="--release"`, `.clean_targets="$(TARGET_DIR)"`, `.libdir="release"`, `.target=""`, `.panic_exports=""` ⇒ output byte-identical to committed `src/Makevars`. - Unix `src/Makevars.in` also carries `@TARGET@`/`@PANIC_EXPORTS@`; do not modify it (out of scope).
- Reference roxigdal `Makevars.win.in` lines: `TARGET` (1), `TARGET_DIR/LIBDIR/STATLIB/PKG_LIBS` (3–6), `libgcc_mock` (18–19), cargo build with `LIBRARY_PATH` to mock (35–37), then a `cargo run --bin document` step (39–42) that must be dropped for rxet, cleanup (45), `rust_clean`/`clean` (47–51).
