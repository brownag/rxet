## Notes
- Name map applied: all bindings are `rxet_*` in `R/extendr-wrappers.R` (lines 28, 31, 34, 39, 42, 46). None are exported. Old `.xet_*` names are absent.
- `is_compiled()` in `tests/testthat/helper-local-cas.R` (lines 11-23) probes `wrap__rxet_init_client` and returns FALSE on error. It is already in the new form.
- `R/stream_connection.R` `xet_open_stream_connection` (lines 54-64): `id <- rxet_open_reader(...)`, finalizer guard on `id`, `reader` and `close_fun` closures, `rxet_stream_connection(reader, close_fun, id)`. The offline helper copies the closures and omits the guard/finalizer, since no client is involved.
- `src/rust/src/lib.rs` `rxet_memory_reader_open(bytes: Raw)` (line 75) returns the reader id string. `rxet_reader_is_open` (line 159) returns a bool.
- Past-end reads: `src/connection.c` `rxet_conn_read` clamps the length to `size - pos` before calling `read_fun`, so `readBin` returns short. `read_at` in `src/rust/src/reader.rs` (line 123) errors only for requests that exceed the file size, and the C layer never sends one.
- Out-of-range seeks error from C (`src/connection.c` line 73: "Xet connection seek is outside the file (0 to N)"). The message matches the required "outside the file" regex.
- Closed-connection behavior: `rxet_conn_close` calls `close_fun` once. The test-stream-connection test already asserts `readBin` on a closed conn errors "invalid connection". Assertions there are unchanged.
- Existing comment at `tests/testthat/test-stream-connection.R` line 52 ("closing a stream connection releases its reader") reads as if reader release is checked. Its body only checks that reads error after close. The stale part is the test name and the comment wording, so the fix is comment-only.
- Risk: no finalizer backstop in the offline helper. A test that fails before `close` leaks one reader in the registry until the R session ends. Acceptable for tests; each test closes its connection.
- Risk: `devtools::test` loads the package namespace, so `.rxet_close_reader_quietly` resolves without `:::`.
- Risk: `readBin` on a closed custom connection error text may differ by R version; the existing test already relies on "invalid connection".
