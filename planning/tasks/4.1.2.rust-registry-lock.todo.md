Risks:

- `Rscript -e 'devtools::test(filter="client")'` triggers a Rust build through pkgbuild and may be slow on first run; it exercises `test-client.R:33` and `:41` (`"invalid"` close error text, unchanged).
- `cargo check` does not validate the R side; the `devtools::test` step is the only R-level check.
- Removing `Drop` changes no observable behavior (the placeholder spawned an empty task).
- H1: `xet_close_client` error text must stay "invalid or already-closed client handle". This task does not edit it.
- Error ordering: the change replaces only the lock/lookup lines. Argument validation that currently runs before the lookup (e.g. `file_size` checks in `xet_stream_raw` L117–123, `xet_download_file` L243–249) stays before `acquire_client`, so error precedence is unchanged.
