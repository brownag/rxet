- Helper (`tests/testthat/helper-local-cas.R`): `make_fixture_bytes` (116), `upload_fixture` (122), `assert_roundtrip` (136). `start_local_cas` (77), `stop_local_cas` (107), `skip_without_local_cas` (35).

**HF_HOME isolation:** every test that uploads calls `start_download_client()`, a copy of `start_upload_client()` that sets `HF_HOME` to a fresh `tempfile()`, starts the server, and restores `HF_HOME` on exit. Helpers in other test files are not shared, so the copy lives in this file. Reusing one client across tests is not allowed; each test calls the helper.

**Planned test names** (testthat `test_that` titles):
1. `"64 KiB disk download is byte-identical and has the exact size"`
2. `"xet_stream_raw returns the full 64 KiB byte-identical"`
3. `"range boundaries on a 4 MiB multi-chunk fixture are byte-exact"`
4. `"xet_stream_range rejects an empty range and an end past EOF"`
5. `"xet_open_connection reads 64 KiB byte-identical and closes cleanly"`
6. `"disk download leaves no .part file beside dest"`
7. `"two downloads on the same client yield identical bytes"`

**Range arithmetic** (4 MiB = 4194304 bytes; expected = `bytes[(start+1):end]`, 1-based R indexing):
- `[0, 1)` → `bytes[1:1]`, length 1
- `[0, 4096)` → `bytes[1:4096]`, length 4096
- `[4095, 4097)` → `bytes[4096:4097]`, length 2 (crosses the 4096 boundary: byte 4095 is the last of the first 4 KiB block, byte 4096 is the first of the next)
- `[size-1, size)` = `[4194303, 4194304)` → `bytes[4194304:4194304]`, length 1
- `[1000003, 1500017)` → `bytes[1000004:1500017]`, length 500014 (mid-chunk; the start is not on a 4 KiB boundary: 1000003 mod 4096 = 1000003 − 244×4096 = 1000003 − 999424 = 579)

**Constraints honored:** only `tests/testthat/test-local-download.R` is created. No `R/`, `src/`, `DESCRIPTION`, helpers, or other test edits. No `HF_TOKEN`. No Hugging Face upload. Fixtures come from `make_fixture_bytes` and `upload_fixture` in the test, never `tests/fixtures/`. All temp paths use `tempfile()`. No write into the repo or `./local_cas_data`. No commit, no checkout/restore/rm, no staging of `src/Makevars` or `src/entrypoint.o`. Server binary is passed by full path via `RXET_LOCAL_CAS_SERVER`.

**Risks:**
- Same-bytes dedup (5.2.1 finding): each test has its own `HF_HOME`, so dedup does not cross tests. Within test 7 the upload happens once, so there is no re-upload.
- The 4 MiB fixture uploads take longer than 64 KiB; acceptable.
- `xet_stream_range` for a 4 MiB file goes through the range path, not the whole-file path, so the boundary cases exercise real range requests.
- The `readBin` on a connection from `xet_open_connection` assumes a binary-readable connection; if it returns a text-mode connection, the test fails and I stop and report rather than change product code.
- Unknown reconstruction returns HTTP 416 (not 404); not exercised here (that is 5.3.1).
