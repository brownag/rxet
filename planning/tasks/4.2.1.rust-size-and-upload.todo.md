# 4.2.1 — rust-size-and-upload

## Goal
Make every Rust size conversion checked, cap in-memory reads at 2^31 − 1 bytes before any handle lookup or allocation, use fallible allocation, and reject upload reports that do not contain exactly one file, all in `src/rust/src/lib.rs` only.
