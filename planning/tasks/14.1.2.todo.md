# 14.1.2 -- C: EOF whole items, PROTECT, seek previous position (F2, F14, F15)
## Goal
Update `src/connection.c` to round reads at EOF down to whole items without consuming unreturned bytes, protect `Rf_ScalarReal` allocations during call construction, and return the previous position on seek, updating corresponding seek assertions in offline and stream connection tests and adding an EOF whole-item read test.

## Notes
- `rxet_conn_read` previously advanced `pos` by clamped `total` even when `total / size` truncated fractional items, dropping unaligned tail bytes. Rounding down to `total - (total % size)` and checking `total == 0` fixes F2.
- `Rf_ScalarReal` allocations passed directly to `Rf_lang3` risked garbage collection before call construction. Storing and protecting both scalar SEXPs before `Rf_lang3` fixes F14.
- R's `seek()` documentation specifies returning the position prior to any move for non-NA `where`. Capturing `previous` before changing `st->pos` fixes F15.
- Constraints honored: No R code in `destroy` (H4). `rxet_connection_new` signature untouched. Only documented `R_ext/Connections.h` fields used. Package installed only into `.development/lib` (H11).
- Files in scope respected: strictly modifying `src/connection.c`, `tests/testthat/test-connection-offline.R`, and `tests/testthat/test-stream-connection.R`.
