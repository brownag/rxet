Planned helper signatures (all in `tests/testthat/helper-local-cas.R`):
- `local_cas_binary() -> character(1) | NA`
- `skip_without_local_cas() -> invisible NULL` (calls testthat skips)
- `start_local_cas() -> list(endpoint = chr, proc = processx::process)`
- `stop_local_cas(handle) -> invisible(NULL)`
- `make_fixture_bytes(n, seed = 1L) -> raw`
- `upload_fixture(client, bytes) -> list(hash, file_size, sha256)`
- `assert_roundtrip(client, bytes) -> invisible(TRUE)` (expectations inside)

Constraints honored: no `R/**`, `src/**`, `helper-mock-backend.R` edits; no `HF_TOKEN`; no non-loopback endpoint; no repo or `./local_cas_data` writes (data in-memory; temp files via `tempfile()`); no commit; no `Makevars` or `entrypoint.o` staging; no Imports change.

Risks:
- Windows / processx: `kill()` on Windows terminates without SIGTERM; `wait(timeout)` must be called after kill to reap. Piped stdout/stderr are not drained; the server log was empty at default verbosity, so a pipe-buffer block is unlikely, but if the server ever fills the pipe it will stall. Mitigation option: send stdout/stderr to `tempfile()` files instead of `"|"`. The spec says `"|"`; I will follow the spec and flag it.
- Port retry: a free-port probe is racy. Bind failure shows up as the process exiting early, so the retry loop checks `is_alive()` each poll and retries on a new port (max 20).
- 416 response: the harness does not probe unknown reconstructions. The smoke test checks only TCP connect and clean exit. Failure assertions are deferred to 5.3.1.
- Test duplication: `is_compiled` will exist in two helper files until 5.1.2 deletes the mock helper. testthat sources both; identical definitions are harmless.
