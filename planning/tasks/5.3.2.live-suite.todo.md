## Notes

**Probe plan (step 1).** Scratchpad-only R script. Read-only `curl -sS -o /dev/null -w "%{http_code}"` GET to `https://huggingface.co/api/datasets/brownag/rxet-test-data/xet-read-token` (anonymous, no header). If 200, parse the JSON in memory and print only the `casUrl` value (endpoint, not secret). Never print the body. Tree GET `https://huggingface.co/api/datasets/brownag/rxet-test-data/tree/main` to confirm the oid and size. Then `RXET_LIVE_TESTS=1`, `HF_HOME=<scratchpad tempdir>`, `xet_client_new("https://cas-cf.huggingface.co", "")`, `xet_download_file` of `LIVE_HASH`. Output: success or the error class only. The probe writes into the scratchpad `HF_HOME`, not the developer cache.

**Endpoint decision.** `https://cas-cf.huggingface.co`, the default in `with_test_client` (`helper-test-client.R` line 11). If the read-token GET returns 200 with a `casUrl` that differs, stop and report (Question 3 style). If it returns 404 as in recon, the endpoint stays the default and the probe records that it could not be confirmed from the hub.

**Token.** `token <- Sys.getenv("HF_TOKEN")` passed as-is. Empty string if the anonymous probe succeeds. If the probe fails anonymously and `HF_TOKEN` is unset, see Question 3.

**Private HF_HOME.** Every live test calls `start_live_client()`, which sets `HF_HOME` to `tempfile("hf_home_")` and restores the old value in `on.exit`. Copy of the `start_download_client()` pattern from `test-local-download.R` lines 7–16. No helper file is added (`helper-*.R` is outside Files).

**Constants.** `LIVE_REPO <- "brownag/rxet-test-data"`, `LIVE_HASH <- "4e99cb45a4ad980707548c95f5cc3dadb91e36889c68adbff641e56c53981331"` (matches `hf_test_files.R` `HF_TEST_FILES$parquet$hash`), `LIVE_SIZE <- 2931`, `LIVE_SHA256 <- "c25ed568c3f701e640a6d9db7495b8d989ee2f6dbaf3fc0ad2216c6d5cd28bf4"`. `LIVE_SIZE` is passed as a double (2931), matching the existing tests.
