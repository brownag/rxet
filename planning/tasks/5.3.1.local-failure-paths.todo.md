**Probe plan**
- Probes run only in `$SCRATCH` (the scratchpad). Server runs with `--in-memory`. Probe R scripts set `HF_HOME` to a `tempfile()`. No `HF_TOKEN`, no Hugging Face calls, nothing written into the repo.
- Auth probe: wrong token, no token, valid-looking token against the same routes. Record codes.
- Size probe: 65536 bytes uploaded, download with 65537. Record error text (checked for token leakage later) and byte equality.

**HF_HOME isolation**
- Every test that uploads (size-mismatch) gets its own `HF_HOME` through `start_failure_client()`, copied from `start_upload_client()`. Invalid-hash and endpoint-down tests also run inside the same helper, so the cache is never shared with the developer's `~/.cache/huggingface/xet`.

**Planned test names**
- `invalid hash: xet_download_file errors and leaves no dest or .part`
- `invalid hash: xet_stream_raw errors and returns no value`
- `size mismatch: pinned behavior (error or exact bytes), never truncated`
- `auth: wrong or missing token is rejected` (skipped with the probe reason if the probe shows no enforcement)
- `error messages never contain the token`
- `endpoint down mid-session: download errors within 60 s and leaves no dest`
- `local server process is not alive after stop_local_cas`

**Constraints honored**
- Only `tests/testthat/test-local-failures.R` is created. No `R/`, `src/`, `DESCRIPTION`, helper, or other test edits.
- No `HF_TOKEN`, no upload to Hugging Face, no writes into the repo or `./local_cas_data`. All paths via `tempfile()`.
- No commit, no `git checkout`/`restore`/`rm`, no staging of `src/Makevars` or `src/entrypoint.o`.

**Risks**
- `devtools::load_all` (run by the acceptance command) rebuilds `src/Makevars` and `src/entrypoint.o`, as in 5.1.1. Those changes stay unstaged.
- Endpoint-down: a connection-refused error should return quickly, but the phase4 env seam bounds retries, so the 60 s bound is reachable only if the seam is set. The seam is copied locally.
- Size-mismatch outcome is unknown until probe 3; the test pins whatever it shows.
- `processx` is in `Suggests` (J1); the file must skip if it is missing.
