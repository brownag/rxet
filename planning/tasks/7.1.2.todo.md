## Questions

1. The acceptance runs the script "from a scratch directory", so this plan writes outputs to `getwd()`. Confirm that is wanted, not a fixed path inside `tests/testthat/fixtures/`.
2. The spec says each package is guarded, but writing GeoJSON by hand needs no sf. Confirm the hand-written GeoJSON approach (sf stays Suggests-only, unused by the generator), or ask for `sf::st_write` instead (its output bytes may vary with GDAL version).
3. Parquet and GeoTIFF bytes depend on arrow and GDAL versions. Confirm that a PROVENANCE note plus hashes for the pinned versions is acceptable, not a stronger guarantee.
4. Licence: confirm CC0 1.0 stated inside `PROVENANCE.md` only (no separate LICENSE file in the fixtures directory, which is outside the Files list).
5. Raster content: confirm 16x16, one band, EPSG:32633 with extent 500000-500160 E and 4500000-4500160 N, values from seeded `runif`, rounded to 4 decimals.
