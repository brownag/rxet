## Notes
- Fixture facts (verified by reading `tests/testthat/fixtures/make_fixtures.R` and `PROVENANCE.md`): `small.tif` is 16x16, 1 band, Float32, EPSG:32633, 2240 B, seed 20260102, `round(runif(256), 4)` via `terra::values<-`. `small.geojson` is 3 Point features (names a, b, c), 529 B.
- Cell order (confirmed): `make_fixtures.R` runs `terra::values(r) <- round(runif(256), 4)`. terra assigns a vector to cells 1..256 in order. Cell numbering is row-major from the top-left, so `terra::values(r)[, 1]` is the seeded sequence in order. Checked: the committed `small.tif` values equal the seeded sequence within 1e-6 (max abs diff 2.9e-8, Float32 storage). Exact `identical()` fails because of Float32, so the test uses tolerance 1e-6.
- Values are compared to `set.seed(20260102L); round(runif(256), 4)`, the generator's output, not to terra reading the committed file.
- Helpers (`tests/testthat/helper-fixtures.R`): `fixture_path()` (:6), `start_fixture_client()` (:12, cleanup on exit), `serve_fixture()` (:31, returns list with `hash`, `file_size`). `skip_without_local_cas()` at `tests/testthat/helper-local-cas.R:35`.
- Product (`R/spatial.R`): `read_xet_raster` :58, body writes bytes to `tempfile()` with `on.exit(unlink)` at :69-71, `terra::unwrap(terra::wrap(rast))` at :74. `read_xet_vector` :132, `sf::st_read(path)` at :148.
- Temp check: `list.files(tempdir(), full.names = TRUE)` before and after each read call. Snapshot is taken after `serve_fixture()` so the upload does not count.
- Lazy-read hazard (from 7.2.2a): values must be read after the call returns; the test does so.
