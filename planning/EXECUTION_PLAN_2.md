# Execution Plan 2 — Correct Public API, Documentation, and Package Metadata

This is orchestration plan 2 for `/wave-orchestration`. It corresponds to **Phase 2** of `planning/MASTER_PLAN.md`. It builds on the frozen v0.1 contract in `planning/EXECUTION_PLAN_1.md` / `STATE_1.md`.

## Goal & Scope

### Goal

Make the shipped `README`, help pages, exports, and package metadata describe only what `rxet` actually does, in the terms fixed by the Phase 1 v0.1 scope contract. Remove every capability claim that the code does not substantiate (zero-copy, parallel download, push-down filtering, speed numbers, Tokio/LRU architecture, the phantom `xet_get_file_metadata()`), correct return-value/example mismatches, resolve the `read_xet_parquet_stream()` export-vs-internal conflict, fix the license metadata check NOTE, declare test-only dependencies accurately, and make the package test suite actually run under `R CMD check`. This phase is documentation, metadata, and test-harness plumbing only — it does not change Rust behavior, fix concurrency/atomicity (Phase 4), or verify live network behavior (Phase 5).

### In scope

- Reconcile the 13 NAMESPACE exports, `.Call` registrations, and `man/*.Rd` pages; keep all 13 exports (no removal).
- Resolve `read_xet_parquet_stream()` as **exported and honestly documented** (decision D1).
- Remove the phantom `xet_get_file_metadata()` claim and all other stale/overclaimed README statements (Phase 1 stale-claim disposition table).
- Correct `xet_stream_raw()`/`xet_stream_range()` docs and examples to the real `raw()` return; correct range example.
- Relabel the `experimental pending evidence` APIs (Phase 1's 9, plus `read_xet_parquet_stream`, promoted from "deferred support claim" to experimental by D1 — 10 total) as experimental in user-facing docs (decision D3).
- Fix `DESCRIPTION`: `License: Apache License (>= 2) + file LICENSE`; bound the `Description` wording; declare `rprojroot`, drop unused `withr`/`future`.
- Rewrite `README.Rmd` + render `README.md` so both stay consistent.
- Fix the `AGENTS.md` handle model (character UUID handles, not integer `u32`).
- Add the standard `tests/testthat.R` runner and make the suite skip cleanly when optional packages (`uuid`, `arrow`, `future.apply`) are absent.
- Verify from a clean source archive that `R CMD check` has no code/doc mismatch and no license metadata NOTE.

### Out of scope / explicit deferrals

- Rust behavior, mutex-held network I/O, atomic download, size/offset limits, `Drop` cleanup — **Phase 4**.
- Live/real Xet success evidence, byte-integrity, upload/auth/commit semantics, test-assertion correctness, mock rewrites — **Phase 5**.
- Proving Arrow/terra/sf actually accept the returned `rawConnection`; memory/I/O design — **Phase 6**.
- hf-xet pinning, Cargo.lock policy, MSRV/R-minimum, Windows/macOS build validation, vendoring — **Phase 3**.
- CRAN submission, `URL`/`BugReports` metadata, release notes, final release diff review — **Phase 7**.
- Any API removal or renaming. All 13 exports remain.
- Changing the default endpoint `https://cas-cf.huggingface.co`.
- Editing `src/` (Rust) or `.Rbuildignore` build rules.

## Hazard notes

- **`DESCRIPTION` is written by two mechanisms** — roxygen regeneration (`RoxygenNote`) and metadata edits. They are merged into task `2.1.1`; never split them across parallel workers.
- **roxygen2 8.1.0 vs `RoxygenNote: 7.3.3`**: regeneration will bump `RoxygenNote` and may reformat several `man/*.Rd` pages. Accept the full regenerated set; do not hand-edit `man/`.
- **`README.md` is generated from `README.Rmd`** and `.Rbuildignore` excludes the Rmd; edit the Rmd and render, then confirm both match.
- **License semantics:** `+ file LICENSE` requires `LICENSE` to contain only the copyright stanza (it does). `LICENSE.md` stays `.Rbuildignore`d — do not add it to the archive or reference it from DESCRIPTION.
- **Adding `tests/testthat.R` changes check behavior**: the suite will now run inside `R CMD check`. Missing optional packages must produce skips, not errors. `uuid`, `arrow`, `covr` are absent locally; `future.apply`/`sf`/`terra` are present. A `skip_if_not_installed()` inside `setup()` skips the whole file (verified with testthat 3.3.2), which is required because `create_test_fixtures()` runs in `setup()`.
- **`devtools::test()` defaults to `stop_on_failure = FALSE`**: an acceptance command using it must pass `stop_on_failure = TRUE` or it exits 0 even when tests fail.
- **Unexported helpers** (`make_result`, `determine_action`, `evict_*`, `maintain_cache`, `format_action`) are exercised by tests via the namespace environment used by `test_check()`. Do not "fix" this by exporting them.
- **No API removal** — all 13 exports stay; labeling bounds the claim only.
- **`planning/` is not in `.Rbuildignore`**, so it currently ships in the source archive. Out of scope for this phase; recorded and deferred to Phase 3/7.
- **Do not overwrite user artifacts**: `rxet.Rcheck/` and `rxet_0.1.0.tar.gz` are untracked user state; run any build/check in a scratch directory (`/tmp/opencode/...`).
- **No `rg`** in this environment; use `grep`/`grep -E`.
- **Rust/`src/` is out of scope** for every task in this plan.
